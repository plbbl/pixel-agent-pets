CODEX · OFFICIAL NINE STATES

住进官方宠物位

只添加官方兼容图集，按 9 种固定状态播放。应用、签名与 CLI 不变，使用原来的宠物位置。

curl -fsSL https://raw.githubusercontent.com/plbbl/pixel-agent-pets/main/install.sh | bash -s -- --codex

安装后在「Mini 与虚拟宠物」刷新并选角色。Claude、GPT、DeepSeek 有高清／80px 资源选项；官方「外观」可调 80–224px，Clawd 保留原像素。

不包含完整 66 动作自动触发、中文剧情或字幕。思考、输出与工具共用官方 running 状态。

DEEPSEEK HARNESS · FULL LIBRARY

直接住进输入框

66 套完整动作，跟随真实发送、思考、输出、工具与完成状态。先启动官方 DSH 网页版，再复制命令。

curl -fsSL https://raw.githubusercontent.com/plbbl/pixel-agent-pets/main/install.sh | bash -s -- --dsh

单个网页 profile 自动选择，多个时询问。重开后右键调整角色、大小与清晰度；完整剧情与字幕均保留。

无需克隆、npm install 或宠物 API Key。已有损坏配置会停止并保留，不更改其他插件、模型与权限。
