先启动过官方 DSH 网页版，再复制命令。单个网页 profile 自动选择，多个时询问；右键调整宠物。

curl -fsSL https://raw.githubusercontent.com/plbbl/pixel-agent-pets/main/install.sh | bash -s -- --dsh

无需克隆仓库、npm install 或宠物 API Key。重开对应网页窗口即可；已有损坏配置会停止并保留原配置，不更改其他插件、模型与权限。
