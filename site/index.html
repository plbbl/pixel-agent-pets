A

CODEX · NATIVE PET SLOT

住进原生宠物位

四个角色，使用 Codex 原来的宠物窗口和状态触发。当前兼容图集为 9 种固定状态；同一窗口播放完整动作仍需扩展展示层。

选择原生宠物 ↓

沿用官方宠物位置，不增加悬浮窗口，不修改 CLI 内核。

从源码安装
git clone https://github.com/plbbl/pixel-agent-pets.git
cd pixel-agent-pets
npm ci
node scripts/cli.mjs install --codex

需要 Node.js 20+。只安装宠物素材，不修改官方应用。

B

DEEPSEEK HARNESS · PLUGIN

直接住进输入框

安装到官方 DSH 的 web profile，右键切换宠物。66 套动作，随真实任务状态自动出场。

node scripts/cli.mjs install --dsh --profile web

先克隆仓库并运行 npm ci，再执行上面的命令。重开对应的 DSH profile 即可。

查看完整步骤 ↗
选择 Codex 原生宠物9 种固定状态 · 精简图集

点击角色安装到官方宠物列表。这里是精简兼容版；上方剧场可以完整观看所有动作，DSH 插件也保留完整动作。Codex 原生位置的完整播放器目前尚未实现。

本地安装后按 ⌘, → Mini 与虚拟宠物 → 圆形刷新箭头 → 选中角色。
