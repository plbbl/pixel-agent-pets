从源码安装
git clone https://github.com/plbbl/pixel-agent-pets.git
cd pixel-agent-pets
npm ci
node scripts/cli.mjs install --codex-full

需 macOS 13+ 与 Xcode Command Line Tools。预编译 App 无需 Node.js。
