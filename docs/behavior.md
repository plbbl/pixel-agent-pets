# 动作与状态逻辑

本项目提供三个版本：**独立桌宠、官方 DSH 完整插件、Codex 官方 9 状态兼容图集。**DSH 和 Codex 使用已有客户端界面，独立桌宠单独运行；均不修改模型内核。Codex 应用与签名也不变。

## 独立桌宠

独立桌宠使用同一套完整动作素材。默认自动跟随最近活跃的本机 Codex／DSH 任务；右键／托盘可固定来源或关闭跟随。Codex 增量读取有限的近期主会话状态事件，排除子代理；DSH 插件订阅公开服务端事件并写入仅本机使用的小型事实文件，网页在后台也能跟随。

行为优先级为真实工作与等待 → 完成／错误／停止反馈 → 手动演出 → 鼠标互动 → 自主活动 → 久闲休息。来源或会话切换会重置显示上下文，避免把切换误当作完成。跟随关闭、无可用来源时进入自主模式。

单击摸摸，连续摸触发不同反应；悬停停留后回应并有冷却；拖动开始暂停休闲，松手后按位移播放落地反馈。原生拖动由本窗口手势状态兜底，不依赖网页一定收到 pointerup。久闲休息，点击唤醒；真实任务可唤醒休息状态并接回工作动作。手动完整剧情不会被普通悬停打断。

没有全局键盘监听或模型调用。只处理白名单状态；用户新中文输入仅产生布尔触发值，不保存原文、工具参数、命令输出或凭据。DSH 旧后台进程不会自动加载新插件，需要任务结束后正常重启网页服务，单刷新网页不够。

经典演出链为 Claude 中文彩蛋、GPT「探针→门禁→冒烟→验收矩阵→开工」、DeepSeek「没饭→讨饭→吃饭→偷饭→晕碳」。每个片段完整播放，字幕置于角色上方。

## DSH：完整播放器

`src/player.ts` 与 `src/policy.ts` 管理四角色的 66 套原始动作，包含 Claude 的完整 195 帧剧情。行为输入只有运行状态、阶段、等待确认、工具名称与事件标识，以及当前草稿是否含中文等小型事实。

| 实际状态 | 播放逻辑 |
|---|---|
| 等待授权、提问或确认 | 等待动作优先，让位于用户输入 |
| 停止或中断 | 停止反馈，不当作正常完成庆祝 |
| 新错误 | 错误反馈，不替模型重试 |
| 新一轮开始 | 短发送动作，忙碌时约 900 ms 后跟随实际阶段 |
| 准备或思考 | 思考；持续 12 秒后 GPT 使用矩阵动作，DeepSeek 使用长思维链 |
| 工具运行 | 读取／搜索、写入、命令按类型映射；GPT 命令反馈轮换 |
| 文字输出 | 打字或快速输出 |
| 实际重试中 | 重试反馈，继续跟随客户端 |
| 正常完成 | 按角色轮换庆祝 |
| 空闲 | 轮换休闲动作；睡觉需至少空闲 90 秒 |

工作状态来自真实客户端；休闲轮换与手动预览不会生成任务或模型请求。持续工作停在作者指定的姿势，避免反复重播开头。右键切换角色、大小、清晰度和预览完整动作；繁忙或等待确认时不接受手动预览。

宠物默认跟随输入框，首页与会话页使用同一绑定规则。拖动超过 5px 才解除绑定，松手保存自由位置；右键「重置位置 · 跟随输入框」恢复。拖动只更新显示坐标，不重建画布或动画播放器，不改变任务状态。

显示大小为 80–224px。自动清晰度结合大小与屏幕像素密度选择 80／160／320px 源；Clawd 保留原版像素。调整显示不重置当前动作时钟；高清按 16 帧分块载入，解码后切换，缓存上限为两项、24 MiB。隐藏时停止绘制并释放缓存；减少动态效果使用静态姿势。

网页插件注册 `conversation.input.overlay` 和 `shell.overlay`，从当前官方 UI 投影发送、思考、输出、工具、等待、重试、错误和中断。服务端仅通过官方 `webServer` 提供本包清单允许的高清 PNG 与元数据，限制 GET／HEAD 和包内路径；不注册 agent 工具、不改变 provider 或授权策略。

任务投影不保存或上传聊天正文、工具参数、命令输出或密钥；草稿仅计算“是否有中文”。插件不扫描本机 session 文件，不控制 CLI。

## Codex：官方 9 状态图集

Codex 自己读取 `pet.json` 和 `spritesheet.png`，管理宠物窗口、位置、大小与任务状态。本项目只安装兼容素材，不接入额外播放器，不修改应用文件、签名或 CLI。

| 官方状态 | 实际触发 | Claude | GPT | DeepSeek | Clawd |
|---|---|---|---|---|---|
| idle | 无任务活动 | 张望 | 好奇张望 | 等待 | 眼睛张望 |
| running-right | 向右拖动 | 移动反应 | 摆动 | 偷饭奔跑 | 跑步 |
| running-left | 向左拖动 | 镜像移动 | 镜像摆动 | 镜像奔跑 | 镜像跑步 |
| waving | 官方问候交互 | 开心 | 挥手 | 开心 | 挥手 |
| jumping | 官方跳跃交互 | 跳跃 | 跳跃 | 跳跃 | 跳跃 |
| failed | 任务失败 | 受挫 | 出错 | 受挫 | 扶额 |
| waiting | 授权、提问、计划确认 | 指向确认 | 门禁检查 | 饥饿等待 | 指向 |
| running | 执行任务 | 思考 | 思考 | 雷霆思维链 | 思考 |
| review | 完成且结果未读 | 开心 | 准备好了 | 开饭庆祝 | 彩纸庆祝 |

**思考、输出与工具共用官方 `running`。**图集不能增加完整动作触发器、观察草稿或显示剧情字幕。完整 66 动作与剧情可在展示页观看，并由 DSH 插件按细分状态播放；Codex 兼容版不具备这一整套触发逻辑。

映射在 `scripts/codex-export.mjs`。Claude、GPT、DeepSeek 提供真实高清源与 80px 像素资源选项；Clawd 保持原像素。官方「Mini 与虚拟宠物 → 外观」可调整大小（80–224px），高清与像素资源从官方角色列表选择。更高源清晰度不改变官方固定帧数与节奏。

## Claude 中文剧情与本地数据

仅在 DSH：空闲时，当前草稿从无中文变为有中文且已过 20 秒冷却，触发 Claude 中文剧情；忙碌时不打断工作。检测的是文字字符，不推断国籍、地点或身份。

“中文？”“检测到中国用户”与封禁印章均为本地角色演出，字幕不发送给模型，BAN 不会封禁真实账户。展示页可独立播放完整演出；Codex 9 状态图集不检测中文或触发此剧情。

两种安装均不读取会话正文，不为宠物请求模型 API。Codex 素材也不需要 sessions 观察器、辅助功能或录屏权限。
