# 动作与状态逻辑

当前可用的是 **官方 DSH 网页插件**。Codex 原位完整播放器与适配源码已经完成，但 macOS 受认可签名条件尚未满足，自动安装暂不可用，真实原位运行未通过验收。当前方案不创建额外悬浮窗口；旧独立窗口仅作为归档源码保留。

## 共享播放器与行为策略

DSH 与 Codex 原位源码共用 `src/player.ts` 和 `src/policy.ts`，不是把完整动作压成官方 9 行图集。四个角色共有 66 套原始动作；Claude 的完整剧情保留 195 帧。行为输入只有运行状态、阶段、等待确认、工具名称及事件标识、当前草稿是否含中文等小型事实。

| 实际状态 | 播放逻辑 |
|---|---|
| 等待授权、提问或确认 | 等待动作优先，立即让位给用户输入 |
| 停止或中断 | 播放停止反馈，不当作正常完成庆祝 |
| 新错误 | 错误反馈；不会替模型重试 |
| 新一轮开始 | 短发送动作，忙碌时约 900 ms 后让位于当前阶段 |
| 准备或思考 | 思考动作；持续 12 秒后 GPT 使用矩阵动作，DeepSeek 使用长思维链动作 |
| 工具运行 | 读取／搜索、写入、命令等按工具类型映射；GPT 的命令反馈轮换 |
| 文字输出 | 打字或快速输出动作 |
| 实际重试中 | 重试反馈，继续跟随客户端真实状态 |
| 正常完成 | 按角色轮换庆祝动作 |
| 空闲 | 每隔一段时间轮换休闲动作；睡觉需要至少空闲 90 秒 |

只有真实工作状态会触发相应工作动作；空闲轮换与手动预览不会生成模型请求或伪造任务事件。等待确认、停止和错误可以打断短暂的发送反馈。工作状态会停在作者指定的持续姿势，避免不断重播开头。

右键菜单提供角色、大小、清晰度和完整动作预览；繁忙或等待确认时不接受手动动作预览。切换角色会释放旧播放器、计时器和图片缓存，不会自动跟随模型名称覆盖用户选择。

显示大小为 80–224px，自动清晰度结合大小与屏幕像素密度选择 80／160／320px 源。Clawd 保留原版 80px 像素；大小仍可调。调整大小或清晰度不重置当前动作时钟，图片解码后才替换画面。高清按 16 帧分块载入，图片缓存限制为两项、24 MiB；隐藏时停止绘制并释放缓存，恢复后按当前工作状态播放。系统“减少动态效果”使用静态姿势。

## DSH：已可用的官方 UI 适配

网页插件注册 `conversation.input.overlay` 和 `shell.overlay` 两个叠加 UI slot，沿用官方输入区与会话。`activityFromDSH` 从当前客户端状态投影阶段、待处理确认、运行工具、重试、错误与中断，不扫描本机 session 文件，也不控制 CLI。

服务端不是空实现：它只通过官方 `webServer` 提供本包清单允许的本地高清 PNG 与元数据，限制 GET／HEAD 和包内路径。它不注册 agent 工具，不改变 provider、会话内核或授权策略。

当前输入框只计算“是否包含中文”，传给播放器的是布尔值。任务投影不保存或上传聊天正文、工具参数、命令输出或密钥。官方 DSH 0.1.0-rc.6 web 的实际显示与隔离安装／检查已核验；其他 profile 的损坏依赖不由宠物安装器修补。

## Codex：原位源码预览，签名阻塞

原位适配代码把 Codex 当前选中的原生活动源投影为同一个 `Activity`。它区分发送、准备、思考、输出、工具、重试、确认、停止与失败；按精确来源键选择任务，不聚合所有会话来猜测宠物应跟随谁。当前没有选定来源时保持空闲。

草稿观察器只读当前聚焦的 `[data-codex-composer]` 编辑区，不遍历历史消息或其他搜索输入框；跨窗口只发送中文布尔值和临时所有者标识。焦点、清空和页面释放均有处理，输入原文不进入跨窗口消息。

共享播放器已通过四角色事件回放、质量／大小切换和 Claude 全部 195 帧的一致性测试。源码挂载目标是原来的宠物位置，CLI、模型提供方与内核不变。

**这些是源码与测试结果，不是已安装可运行的 Codex 功能。**外层应用临时本地签名无法通过 macOS 库验证，所需受认可签名条件尚未满足。生产安装入口在应用写入前停止；不会关闭 Hardened Runtime、库验证或其他安全保护。原位一键安装与真实运行验收尚未完成，不能用额外窗口或精简图集替代。

## Claude 中文剧情

空闲时，当前草稿从无中文变为有中文且已过 20 秒冷却，才会触发 Claude 的中文剧情；忙碌时不打断工作。检测的是文字字符，不推断国籍、所在地或身份。

“中文？”“检测到中国用户”与封禁印章是本地角色表演。字幕不会发送给模型，BAN 不会封禁任何真实账户。完整预览可在动作展示页观看，不需要发送真实请求。
