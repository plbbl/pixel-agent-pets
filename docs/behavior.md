# 状态逻辑

## Codex：完整动作伴侣

这是独立的 macOS 原生透明小窗口，使用原始图集播放完整动作；没有把完整视频塞进官方固定帧数的图集，也没有修改官方 Codex 的渲染器。

只读本机 `CODEX_HOME/sessions` 的增量事件。启动时只查看最近三天最多 24 个文件的末尾 128 KiB，之后由文件系统事件通知驱动；单行最大 256 KiB，内存仅保留小型活动状态。事件格式不是稳定 API，未知记录会被忽略，云端未落到本机的会话不可观察。

| 事件 | 动作逻辑 |
|---|---|
| 新一轮 / task_started | 短发送动作，然后跟随真实阶段 |
| reasoning | 思考；较长思考触发 GPT 矩阵 / DeepSeek 雷霆链 |
| function_call / custom_tool_call | 工具动作；读取、写入和命令分开 |
| request_user_input / approval 记录 | 等待确认优先 |
| task_complete | 所有活动会话都完成时，轮换庆祝 |
| turn_aborted | 停止动作，不庆祝 |
| terminal error | 错误动作 |
| 中文输入 | Claude 中文剧情，20 秒冷却 |
| 空闲 | 轮换休闲动作；睡觉至少空闲 90 秒 |

并发工具按 call_id 跟踪，一个调用结束不会误判所有工具完成。多个会话聚合时等待优先，其次仍在运行的会话。手动右键“播放完整动作”会播放该动作所有原帧，包括 Claude 的 195 帧剧情，不抽帧压缩。工作状态会在作者指定的停留姿势等待下一次活动，避免反复从头抖动。

原文不写入配置、不上传；提示词只留下“含中文”布尔值。没有辅助功能、录屏、模型 API 或内核调用。角色与位置属于伴侣自身的偏好设置。

## Codex：使用原生状态机

官方桌面应用读取 `pet.json` 与 `spritesheet.png`，本项目只提供图集。状态来自官方任务生命周期，不靠定时猜测，也不依赖额外的后台监听服务。

| 原生行 | 实际触发 | Claude | GPT | DeepSeek | Clawd |
|---|---|---|---|---|---|
| idle | 无任务活动 | 张望 | 好奇张望 | 等待 | 眼睛张望 |
| running-right | 向右拖动 | 移动反应 | 摆动 | 偷饭奔跑 | 跑步 |
| running-left | 向左拖动 | 镜像移动反应 | 镜像摆动 | 镜像奔跑 | 镜像跑步 |
| waving | 官方问候交互 | 开心 | 挥手 | 开心 | 挥手 |
| jumping | 官方跳跃交互 | 跳跃 | 跳跃 | 跳跃 | 跳跃 |
| failed | 任务失败 | 受挫 | 出错 | 受挫 | 扶额 |
| waiting | 授权、提问、计划确认 | 指向确认 | 门禁检查 | 饥饿等待 | 指向 |
| running | 正在执行任务 | 思考 | 思考 | 雷霆思维链 | 思考 |
| review | 完成且结果未读 | 开心 | 准备好了 | 开饭庆祝 | 彩纸庆祝 |

**思考、文字输出与工具执行在原生 API 中共用 running。** 图集不能自行增加触发器，不能读取输入框，也不能加字幕。完整剧情和更细的状态区分由 DSH 插件承担。源动作映射在 `scripts/codex-export.mjs`；所有图集按相同坐标和整数比例导出，空白格严格透明。

## DSH：只读 UI 活动适配

插件只注册 `conversation.input.overlay` 和 `shell.overlay` 两个可叠加 UI slot，不替换官方输入区、侧栏或会话。服务端 `apply()` 为空，不安装 agent 工具、不修改 provider。

1. 等待权限/确认立即优先，覆盖发送动画。
2. 新错误先播错误；新一轮播短发送动作，900 ms 后让位于真实状态。
3. 工具优先于输出，输出优先于思考。读取/搜索、写入、命令分别映射动作。
4. 思考 12 秒后 GPT 使用验收矩阵，DeepSeek 使用雷霆思维链。
5. 结束轮换庆祝动作。空闲轮换休闲动作；睡觉需至少空闲 90 秒。
6. Claude 输入框从无中文变为有中文时播放中文梗，20 秒冷却，忙碌时不打断工作。字幕是本地演出，BAN 不影响任何账户。
7. 右键切换角色并保存；切换角色释放旧播放器、计时器和图片缓存。角色不会自动跟随模型切换，避免覆盖用户选择。

输入框仅提取“是否有中文”布尔值，任务仅提取运行/阶段/工具名称和事件标识。不会保存或上传聊天正文、命令参数或密钥。

状态可在 `npm run preview` 下用模拟按钮测试，无须发送真实请求。测试覆盖过期图片回调、隐藏恢复、停留帧、逻辑优先级、图集完整性、安装备份与插件边界。
