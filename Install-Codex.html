Codex 原生兼容版

需要完整的 66 套动作与字幕？请打开 新版动作剧场与完整 App 下载页。下方仅安装原生精简图集。

像素 Claude、纯白 GPT、DeepSeek 和原版 Clawd。使用 Codex 原生宠物接口，或安装到官方 DeepSeek Harness。

Codex：点角色安装

上面的按钮会请求打开 Codex，并显示官方安装预览。确认后选用即可；浏览器若询问是否打开 Codex，请允许。只下载对应的 PNG，不运行第三方脚本。

本地文件安装后：按 ⌘, → 左侧 Mini 与虚拟宠物 → 宠物列表旁的小圆形刷新箭头 → 选角色。旧版入口叫 Pets。开启宠物显示开关后，它会根据 Codex 自己的任务状态活动。

DSH：安装完整动作

git clone https://github.com/plbbl/pixel-agent-pets.git
cd pixel-agent-pets
npm ci
node scripts/cli.mjs install --dsh --profile web

重新打开这个 DSH profile，右键宠物可随时切换。完整 66 个动作、工作状态与本地短字幕。无需模型请求。

Codex 原生版使用 9 个固定状态；运行中合并思考、输出与工具，完成未读时庆祝，等待确认和出错分别有动作。原生接口不支持完整剧情或自定义字幕。
